### Endpoint Registration and Application Setup (app/main.py)
The `app/main.py` file initializes the FastAPI application, includes routers, and defines global endpoints. An existing `/health` endpoint is present.

```python
from contextlib import asynccontextmanager
from fastapi import FastAPI

from app.database import init_db
from app.routers import merchants, payments, webhooks, reports


@asynccontextmanager
async def lifespan(app: FastAPI):
    await init_db()
    yield


app = FastAPI(
    title="Payment Processing Service",
    description="A payment processing API with merchant management, webhooks, and reporting",
    version="0.1.0",
    lifespan=lifespan,
)

app.include_router(merchants.router)
app.include_router(payments.router)
app.include_router(webhooks.router)
app.include_router(reports.router)


@app.get("/health")
async def health_check():
    return {"status": "healthy"}


@app.get("/")
async def root():
    return {
        "service": "payment-processing",
        "version": "0.1.0",
        "docs": "/docs",
    }
```

## Test Patterns (tests/test_merchants.py)
Tests use `pytest` and `httpx.AsyncClient` to make requests to the FastAPI application. Tests are asynchronous.

```python
import pytest
from httpx import AsyncClient

@pytest.mark.asyncio
async def test_create_merchant(client: AsyncClient):
    response = await client.post("/merchants", json={
        "name": "Acme Corp",
        "email": "billing@acme.com",
        "currency": "USD",
    })
    assert response.status_code == 201
    data = response.json()
    assert data["name"] == "Acme Corp"
    assert data["email"] == "billing@acme.com"
    # ... other assertions ...


@pytest.mark.asyncio
async def test_get_merchant_not_found(client: AsyncClient):
    response = await client.get("/merchants/nonexistent")
    assert response.status_code == 404
```

## Constraints and Gotchas

*   **Existing `/health` endpoint:** The `app/main.py` already contains a `/health` endpoint. The task is to modify this existing endpoint, not create a new one or a new router file for it.
*   **Version retrieval:** The FastAPI `app` object has a `version` attribute (`app.version`) which can be used to retrieve the service version.
*   **Consistent Testing:** New tests should follow the existing `pytest` and `httpx.AsyncClient` patterns, including `@pytest.mark.asyncio`.
*   **FastAPI conventions:** Adhere to existing FastAPI code style and patterns.
